# 📚 Fundamentos Matemáticos (FUM)

Bienvenido/a al repositorio del curso **Fundamentos Matemáticos
(FUM)** correspondiente al cuatrimestre **O2026**.

En este espacio se centraliza todo el material académico del curso,
organizado de la siguiente manera:

* 📝 **Notas del curso.** Desarrollo formal de los temas vistos en
clase.
* 📊 **Diapositivas:** Presentaciones proyectadas en las sesiones.
* ✏️ **Tareas:** Ejercicios para entregar (EP).
* 🧮 **CAF:** Ejercicios básicos de rutina para practicar los conceptos visto en clase.
* 🔗 **Recursos:** Material complementario.
