# 📚 Fundamentos Matemáticos (FUM)

(FUM)** correspondiente al cuatrimestre **O2026**.

* 📝 **Notas:** Apuntes y teoría de clase.
* 📊 **Diapositivas:** Presentaciones proyectadas en las sesiones.
* ✏️ **Tareas:** Enunciados y guías de asignaciones.
* 🧮 **Ejercicios:** Prácticas y problemas resueltos o por resolver.
* 🔗 **Recursos:** Material complementario, lecturas y enlaces útiles.
